# My Portfolio Website

A personal portfolio website built with HTML and CSS to showcase my projects and web development skills.

## Overview

This is my first portfolio website, designed to introduce myself as an aspiring web developer and display the projects I've created. It features a clean, colorful layout with a navigation bar, hero section, project showcase, and footer.

## Features

- **Navigation Bar** — Logo, and links to Home, About Me, Projects, and Contact sections
- **Hero Section** — Personal introduction with a featured banner image
- **Projects Section** — Card-based grid layout showcasing three projects with images and descriptions
- **Footer** — Links to Privacy Policy, Terms of Service, and Contact Information

## Technologies Used

- HTML5
- CSS3 (Flexbox for layout)
